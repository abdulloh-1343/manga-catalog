# ✅ Чек-лист тестирования перед деплоем

Выполните этот чек-лист **локально** перед заливкой реального Firebase конфига.

---

## Подготовка

1. Запустите локальный сервер:
   ```bash
   cd "C:\Users\madae\Desktop\пустая папка для экспериментов\manga-catalog"
   python -m http.server 8000
   ```

2. Откройте http://localhost:8000 в браузере

3. Откройте DevTools (F12) → вкладка Console

## 🧪 Тест 3: Детальная страница (manga-detail.html)

1. Кликните на любую карточку манги

**Базовые проверки:**
- [ ] Страница загружается без редиректа на catalog.html
- [ ] Заголовок манги отображается
- [ ] Градиентная обложка рендерится
- [ ] Рейтинг и жанры показываются
- [ ] Описание отображается
- [ ] Список глав рендерится

**Без параметра ?id:**
- [ ] Откройте http://localhost:8000/manga-detail.html (без ?id=)
- [ ] Должен редиректить на catalog.html
- [ ] НЕ должно быть белого экрана или ошибки

**С неверным id:**
- [ ] Откройте http://localhost:8000/manga-detail.html?id=999
- [ ] Должен редиректить на catalog.html

**Закладки (localStorage):**
- [ ] Нажмите "Добавить в закладки"
- [ ] Кнопка меняется на "❤️ В закладках"
- [ ] Откройте DevTools → Application → Local Storage → http://localhost:8000
- [ ] Должен быть ключ `manga_bookmarks` с `[id]`
- [ ] Перезагрузите страницу (F5) → кнопка остается "В закладках"

**Рейтинг звездами:**
- [ ] Наведите на звезды → они подсвечиваются
- [ ] Кликните на 4-ю звезду → 4 звезды становятся активными
- [ ] Уберите курсор → активные звезды остаются

**Отзывы (гостевой режим):**
- [ ] Поставьте 5 звезд
- [ ] Введите текст: `Тестовый отзыв от гостя`
- [ ] Нажмите "Отправить отзыв"
- [ ] Отзыв должен появиться в списке с именем "Аноним"
- [ ] Форма должна очиститься (звезды и текст)
- [ ] Откройте DevTools → Application → Local Storage
- [ ] Должен быть ключ `manga_reviews` с вашим отзывом

**XSS-тест:**
- [ ] Поставьте 3 звезды
- [ ] Введите текст: `<script>alert('XSS')</script><img src=x onerror=alert('XSS2')>`
- [ ] Нажмите "Отправить отзыв"
- [ ] ✅ НЕ должно быть alert-окон
- [ ] ✅ Текст должен отобразиться как обычный текст (экранированный HTML)

**Рекомендации:**
- [ ] В сайдбаре показывается "Похожая манга"
- [ ] Отображается 4 карточки
- [ ] Клик по карточке открывает детальную страницу другого тайтла
